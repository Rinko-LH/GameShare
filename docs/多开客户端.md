# 同时打开 4 个 GameShare 客户端

在 **PowerShell** 中复制执行下面整段命令：

```powershell
Set-Location 'D:\GameShare\gameshare'

# 构建当前代码，包含最新修改。
npm run build -w @game-share/desktop
if ($LASTEXITCODE -ne 0) { throw '构建失败，请先处理报错。' }

# 确保 Electron 以桌面应用模式运行，并加载刚构建的页面。
$env:ELECTRON_RUN_AS_NODE = $null
$env:VITE_DEV_SERVER_URL = $null

$electronExe = Join-Path (Get-Location) 'node_modules\electron\dist\electron.exe'
$desktopApp = Join-Path (Get-Location) 'apps\desktop'

1..4 | ForEach-Object {
    $clientProfile = Join-Path (Get-Location) ".cache\manual-clients\client-$_"
    Start-Process -FilePath $electronExe -ArgumentList @(
        "`"$desktopApp`"",
        "--user-data-dir=`"$clientProfile`""
    )
}
```

这会打开 **4 个客户端窗口**，每个客户端使用独立配置目录，避免共用缓存和本地设置。配置保存在 `D:\GameShare\gameshare\.cache\manual-clients\client-1` 至 `client-4`，下次使用同一命令会继续沿用。

测试时，选择其中一个客户端创建房间，其余三个加入同一个房间。通常只需一个客户端启动信令服务，其余客户端连接它。

代码没有变化时，可以跳过构建部分，从清除两个环境变量的命令开始执行。再次执行启动循环会额外打开 4 个窗口，建议先关闭上一批测试窗口。

这里启动的是源码构建版本，包含最近的界面修改；不是 `release` 目录里的旧版 exe。
