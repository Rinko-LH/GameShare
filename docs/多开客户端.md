# 在本机双开或三开 GameShare

在 Windows 上安装[开发依赖](BUILD-NOTES.md)，在仓库根目录执行 `npm ci`。然后打开 PowerShell，在同一目录任选一条命令。

```powershell
.\dev-two.bat
.\dev-three.bat
```

两条命令会各自启动一份 Vite 开发服务及两个或三个 Tauri 窗口。窗口共用前端服务，使用 `.cache/manual-tauri-clients/client-1` 至 `client-3` 中各自的 WebView2 配置，例如昵称和连接偏好。再次运行会沿用各自的配置。测试结束后关闭本批实例和开发命令，便于下一批重新使用 Vite 端口 `1420`。

## 测试一个房间

1. 在一个窗口建房，将「用户连线方式」设为「IP直连」，选择本机的可用网络地址。
2. 复制完整邀请，在其余窗口分别填写昵称并粘贴同一邀请入房。此时由房主窗口提供信令。
3. 轮流或同时分享测试源，检查其他窗口里的画面和浮窗。测试源仅提供画面，语音需要单独打开麦克风。验证窗口采集和应用音频时，从共享面板选一个正在播放声音的窗口。

跨设备或跨网络的连通性请按[跨网络测试](REMOTE-TESTING.md)验证。自动测试入口见 [Tauri 集成测试](../apps/tauri/README.md#集成测试)。
