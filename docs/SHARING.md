# 屏幕共享与观看

本页适用于 Windows Tauri 客户端。先使用完整邀请进房，或创建房间并将邀请私发给队友。 [连接选择](CONNECTION-OPTIONS.md)

## 共享你的游戏

1. 打开左侧「屏幕共享」，点击「选择窗口或屏幕」，在 WebView2 的选源面板里选中游戏窗口或整块屏幕。
2. 选择窗口后，GameShare 会尝试采集该应用及其子进程的声音。自动采集失败时会保留画面，可以用「选择音频应用」手动接入。共享整屏时，也可以通过这个按钮单独选择要分享声音的应用。
3. 在同一面板可以打开「本地预览」、更换来源、静音共享声音或停止共享。「测试源」会发送静音动画，适合先检查队友能否收到画面。

游戏优先使用窗口化或无边框窗口化。独占全屏可能影响窗口采集和置顶浮窗。按应用采音建议使用 Windows 11，效果也取决于目标应用。若窗口列表里找不到游戏，先确认窗口已打开且未最小化。 [Tauri 采音说明](../apps/tauri/README.md#采集与观看)

## 开麦和按住说话

在「屏幕共享」的语音区打开麦克风。选择「持续说话」或「按住说话」。按住模式可以使用界面按钮，也可以设置自己的全局快捷键。进入游戏后快捷键仍可用，按键也会传给游戏，设置时请选一个无冲突的键。

按住模式待命期间，麦克风保持就绪，Windows 可能继续显示录音指示。关闭麦克风会释放设备。停止共享画面后，语音可以继续使用。

## 观看与声音控制

- **放大与网格**　进入房间后，在共享画面区选择「放大」或「网格」。放大模式可从缩略图切换主画面。缩略图可能以较低画质送往当前观看者，减少上行用量。
- **全屏与浮窗**　「全屏模式」进入无边框全屏，可按 `Esc` 退出。「浮窗模式」把每路远端共享显示为独立置顶窗口，可调透明度。
- **每位队友独立调整**　用成员画面或浮窗上的控件调节语音和共享声音。还可以暂停接收某位成员的画面。语音继续独立播放。

## 发送画质

发送端可以选择自动、流畅、标清或高清。手动档的分辨率上限分别为 360p、540p 和 1080p，可以另选 30、60 或 120 帧。默认自动档最高 1080p，每位观看者的视频码率上限为 2 Mbps。实际画质受采集源、设备和网络影响。多人都在共享时，可先降低帧率或画质，再对照观看端的画面参数排查。
