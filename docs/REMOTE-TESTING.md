# 跨网络连接测试

使用两台 Windows 电脑和同一版本的 GameShare。异地测试让两台电脑分别使用不同的宽带，或让其中一台接入手机蜂窝热点。记录双方使用的网络和组网状态，方便复现。连接方式的说明见[房间与音视频连接](CONNECTION-OPTIONS.md)。

## 1. 确认房间入口

1. 房主在「房间连接」选择「Cloudflare」和「自动协商」，创建房间。临时网址就绪后，点击「复制邀请」。
2. 朋友选择「加入房间」，粘贴完整邀请，点击下方的「加入房间」。双方都能在成员列表看见对方，说明该次测试的信令和入房已通过。
3. 如果入房失败，从朋友的网络打开信令入口的 `/health`。正常响应包含 `"ok": true` 和 `"service": "game-share-signaling"`。可从来宾的「诊断日志」查看尝试连接的地址，再在浏览器中访问该地址的 `/health`。

`/health` 只验证 HTTP 到达信令服务。自备公网映射还需要传递 Socket.IO 使用的 HTTP 和 WebSocket 流量。若健康页成功而客户端无法入房，应检查公网映射的 WebSocket 支持、完整邀请和房间状态。

IP 直连使用的默认端口为 TCP `8080`。局域网地址要从朋友的网络可达，公网 IP 还要满足入站路由和防火墙条件。完整 IPv6 URL 用方括号包住地址，例如 `http://[2001:db8::10]:8080/health`。

## 2. 验证画面和声音

1. 房主在「屏幕共享」点「测试源」，让朋友确认测试画面连续播放。再由朋友分享一次，检查反方向。
2. 「测试源」是静音画面。要测试应用声音，换成正在播放声音的窗口，确认房主端的共享声音和来宾端的共享声音播放均已开启。要测试语音，双方单独检查麦克风和语音播放。
3. 在主窗口观看画面时开启「画面参数」，查看收到的帧率、码率和音视频实际路径。选中的候选对经过 TURN 时会显示「TURN 中继」，否则显示「端点连接」。通过 UU 等虚拟网卡建立的端点连接，底层仍可能由组网工具中转。

房间连接旁的延迟是信令往返时间。画面参数中的链路延迟反映音视频连接的往返时间。已进房并看到成员但尚无人共享或开麦时，媒体仍处于等待状态。

## 3. 根据现象排查

| 现象 | 下一步 |
| --- | --- |
| 无法复制 Cloudflare 邀请 | 等待临时网址就绪，查看客户端错误提示，检查便携 ZIP 是否完整解压以及 `cloudflared.exe` 是否在主程序旁。房间内如有「重新准备邀请网址」，可用它重试。 |
| 对方访问不了 `/health` | 检查房主客户端和隧道还在运行，或检查映射目标、端口和防火墙。隧道重启后重新发送邀请。 |
| `/health` 有响应，客户端仍无法入房 | 检查房主是否还在该房间、邀请是否完整、应用版本是否支持该邀请。使用自备映射时验证 Socket.IO 实际连接。 |
| 双方已入房，正在分享却没有画面 | 先用「测试源」排除实际窗口的采集问题，再检查双方网卡、虚拟组网和防火墙。跨网自动协商失败时，可用双方可达的虚拟网络，或使用能提供兼容 TURN 凭据的信令服务。 |
| 测试画面可见，实际窗口无声 | 检查共享源是否有声音。房主可用「选择音频应用」指定来源，来宾检查该成员的共享声音开关及音量。 |
| 手动指定 IP 后媒体断开 | 核对各自选择的是本机可被对方访问的 IP，尤其注意虚拟网卡是否断开或换了地址。离房后刷新地址并重新选择。 |

Cloudflare 临时隧道转发房间信令，Tauri 内置信令返回的健康信息中 `turn.enabled` 为 `false`。判断自动协商是否真正用了 TURN，以观看端选中的媒体路径为准。能取得 STUN 候选，只说明发现了一个公网映射，实际能否连通由两个端点和网络共同决定。

如果需要提交问题，可记录双方的版本、房间连接方式、是否入房、是否能互相看到测试源、实际媒体路径以及「诊断日志」中的相关错误。公开分享前遮盖临时网址、房间码、IP 和凭据。

## 开发者复测

在仓库根目录运行以下探测命令。探测结果只代表运行探测的机器及网络。

```powershell
npm run check:network
npm run check:tunnel -- example.trycloudflare.com
```

将示例域名换成当前的临时域名，参数只填域名。前一个脚本从 Node 探测本机地址、STUN 和 NAT 映射特征，后一个检查临时入口的 HTTP 健康页及 Socket.IO 轮询握手。握手返回 WebSocket 升级信息时，仍应由对端客户端实际入房以确认连接。Tauri 自动化集成检查和 `--cloudflare` 参数见 [Tauri 客户端验证](../apps/tauri/README.md)。

上游 Electron 的历史测量和排障记录见[归档版跨网络测试](archive/upstream-electron/docs/REMOTE-TESTING.md)。
